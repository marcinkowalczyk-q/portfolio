I want this site to work for everyone, so I follow WCAG 2.2 Level AA. It has been tested with automated tools (axe, Lighthouse), keyboard navigation and the VoiceOver screen reader.

**Known limitations:** screenshots in the case studies show interfaces I worked on and contain text as images. Their content is described in alt text and captions.

If you run into an accessibility problem, please contact me: [marcinkowalczyk.design@gmail.com](mailto:marcinkowalczyk.design@gmail.com).
